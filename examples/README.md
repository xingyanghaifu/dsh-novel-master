# 示例文件

本目录包含一些示例，帮助你快速了解插件的使用方式。

## 📖 使用示例

### 1. 一键完本

```bash
/novel 网管发现网吧电脑能修仙 80章
```

插件会：
- 创建项目目录 `novel_projects/网管发现网吧电脑能修仙/`
- 生成设定、角色、大纲等文件
- 自动连写 80 章

### 2. 导入已有小说续写

```bash
/novel-continue ./我的旧作.txt 20章 --auto 后面节奏快一点
```

会自动：
- 按「第X章」拆分章节（支持 GBK 编码）
- 导入到新项目
- 续写 20 章

### 3. 学习参考作品的风格

```bash
/novel-study ./参考书籍.txt --to 网管发现网吧电脑能修仙
```

会分析参考书的：
- 平均句长
- 对话占比
- 写作特点

然后生成风格档案，应用到你的项目。

### 4. 其他常用命令

```bash
# 查看项目统计
/novel-stats

# 审校最近5章
/novel-review 最近5章

# 改写第10章
/novel-rewrite 10 节奏加快，增加冲突

# 导出全书
/novel-export html
```

## 📂 生成的项目结构

```
novel_projects/

```

## 🎯 工作流示例

### 完整的创作流程

```bash
# 1. 创建新书项目
/novel 末日求生：我有一座避难所 100章 --auto

# 2. 学习参考作品的风格
/novel-study 参考作品.txt --to 末日求生

# 3. 等待自动写作完成（或暂停后继续）
/goal pause    # 暂停
/goal resume   # 继续

# 4. 审校和修改
/novel-review 最近10章
/novel-rewrite 15 增加情感描写

# 5. 导出成品
/novel-export html
```

## 💡 提示

- 项目文件都是纯文本，可以手动编辑
- 使用 `--auto` 让 AI 自动决策分岔点
- 不加项目名时，命令会自动选择最近修改的项目
- 导入的 txt 文件支持 GBK 编码自动识别
