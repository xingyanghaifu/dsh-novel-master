## 1. ✅ 来源元数据评分（启发式参考）

### 功能说明

`/novel-research` 报告会为每个来源计算一个元数据启发式参考分。它不核验网页内容或事实真伪，不是事实可信概率，也不会自动排序或筛选来源。报告中的所有事实、结论和引用都需要人工核验。

### 评分维度

| 维度 | 权重 | 说明 |
|------|------|------|
| **来源类别** | 60% | 子分数为 0–100；根据 URL 的 hostname 与代码内已知域名后缀规则分档，不检查路径、查询参数或无关主机名中的子串。 |
| **发布日期时效** | 30% | 子分数为 0–100；未知、无效或未来日期记 0 分，不给未来日期加分。 |
| **正文抓取状态** | 10% | 子分数为 0–100；成功抓取记 100，否则记 0，因此抓取最多贡献最终分的 10 分，不是额外加 20 分。 |

**计算方式**：最终参考分 = 来源类别子分数 × 60% + 时效子分数 × 30% + 抓取状态子分数 × 10%，四舍五入并限制在 0–100。该分数只是基于元数据的粗略启发式参考。

### 显示区间

- 🟢 **高区间** (80–100)
- 🟡 **中区间** (60–79)
- 🟠 **低区间** (40–59)
- 🔴 **极低区间** (0–39)

这些只是参考分的显示分档，不代表来源或事实已核实，也不表示可以直接采用；所有事实和结论仍需核对原始来源及其他可靠材料。

### 使用示例

```bash
/novel-research 唐朝服饰文化
```

报告会列出检索来源及各自的元数据启发式参考分。结果不会按分数排序或筛选；请逐项核验原文、来源和事实。

### 报告字段示意

```markdown
## 来源元数据评分（启发式参考）
评分仅反映域名类别、发布日期和抓取状态，不验证内容真伪；所有事实与结论均需人工核验。
- [来源标题](来源 URL) - <0–100 的启发式参考分>（非事实验证）
  来源类别：<0–100> | 时效性：<0–100> | 抓取状态：<0 或 100>
```

## 2. 🧪 热点题材静态演示命令

### 命令：`/novel-trends`

此命令展示插件内置的**静态演示数据**，不是当前热门题材分析。演示包含 6 个题材样例；`7d`、`30d` 和 `90d` 仅作为界面参数显示，三个范围返回相同样例，不会分析对应时间段。

### 使用方法

```bash
/novel-trends          # 显示静态演示样例（默认参数 7d）
/novel-trends 7d       # 静态演示，非最近7天数据
/novel-trends 30d      # 静态演示，与其他范围相同
/novel-trends 90d      # 静态演示，与其他范围相同
```

### 输出边界

- 6 个题材的分值、趋势标签和增长率均为虚构演示数据，不是排行或市场观测。
- 创意组合只是静态灵感示例，不是市场机会预测或推荐。
- 命令不会查询平台榜单、社交媒体或其他实时市场来源；不能据此判断题材需求、增长或入场时机。

### 输出示意

报告会明确标注“静态演示”“非真实排行”和“虚构分值/趋势/增长率”，并展示 6 个题材样例及静态创意组合示例。不要将这些样例当作实测市场结果。

## 3. ⚙️ 模型选择与思考强度配置

### 已有功能增强

你的插件**已经支持**模型选择和思考强度配置！在多个场景中都可以配置：

#### 3.1 引导模型配置

在 DSH 设置界面中 → **小说写作大师** → **引导-写作分离**：

```yaml
guidance:
  enabled: true
  provider: "deepseek"                    # 引导模型供应商
  model: "deepseek-reasoner"              # 引导模型ID
  reasoningEffort: "high"                 # 引导推理强度 (low/medium/high)
  writingProvider: "anthropic"            # 写作模型供应商
  writingModel: "claude-3-5-sonnet-20241022"
  writingReasoningEffort: "medium"        # 写作推理强度
```

#### 3.2 学习总结模型配置

**自主学习总结**部分：

```yaml
learning:
  enabled: true
  summaryProvider: "deepseek"             # 摘要模型供应商
  summaryModel: "deepseek-chat"           # 摘要模型ID
  summaryReasoningEffort: "low"           # 摘要推理强度
```

#### 3.3 决策AI配置

**决策AI**部分：

```yaml
decision:
  enabled: true
  provider: "anthropic"                   # 决策模型供应商
  model: "claude-3-5-sonnet-20241022"     # 决策模型ID
  reasoningEffort: "high"                 # 决策推理强度
  minConfidence: 0.7                      # 置信度阈值
```

#### 3.4 资料检索模型配置

**资料检索**部分（新增思考强度支持）：

```yaml
research:
  enabled: true
  provider: "openai"                      # 检索模型供应商
  model: "gpt-4-turbo"                    # 检索模型ID
  reasoningEffort: "medium"               # 🆕 检索推理强度
  maxResults: 5
  maxSourceChars: 12000
```

## 📊 配置界面说明

### 如何配置

1. 打开 DSH 设置界面
2. 找到 **小说写作大师** 插件
3. 展开对应的配置组：
   - **引导-写作分离** - 任务拆解和写作分离
   - **学习总结** - 自动学习和经验复用
   - **决策AI** - 辅助决策建议
   - **资料检索** - 联网资料搜索

### 推理强度选项

| 强度 | 适用场景 | 速度 | 质量 |
|------|---------|------|------|
| `low` | 快速摘要、简单任务 | ⚡⚡⚡ | ⭐⭐ |
| `medium` | 一般写作、日常分析 | ⚡⚡ | ⭐⭐⭐ |
| `high` | 复杂推理、关键决策 | ⚡ | ⭐⭐⭐⭐⭐ |

留空使用模型默认值。

## 🔧 技术实现细节

### 来源元数据启发式评分

```javascript
// 三项子分均为 0–100；未知/无效/未来发布日期的时效分为 0。
// 成功抓取正文的子分为 100，否则为 0；加权后最多贡献最终分的 10 分。
总分 = 来源类别子分 × 60% + 时效子分 × 30% + 抓取状态子分 × 10%

// 来源类别取决于 URL hostname 与内置已知域名后缀的匹配，
// 不是在整条 URL 中查找任意子串；此元数据评分不验证来源实际权威性。
```

评分仅作提示，不代表事实可信度。报告不会按该分数排序或筛选来源；所有事实和结论都需要人工核验。

### 热点题材数据边界

`/novel-trends` 使用插件内置的 6 个静态演示题材。7d/30d/90d 参数返回同一组样例，不会查询平台榜单、社交媒体或其他实时市场来源。分值、趋势和增长率是虚构演示字段；创意组合不是市场预测或推荐。
