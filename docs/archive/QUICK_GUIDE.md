# 小说写作大师 - 快速使用指南

## 🎯 核心新功能

### 1. 智能资料检索（增强版）

**命令**: `/novel-research <检索问题>`

**新增能力**:
- ✅ 为每个来源计算 0–100 的元数据启发式参考分
- ✅ 展示来源类别、发布日期时效和正文抓取状态的评分明细
- ✅ 生成明确标注“仅供参考、需人工核验”的分析报告

> 评分不验证事实真伪，不会按分数排序或筛选来源；所有事实、结论和引用都需要人工核验。

**使用示例**:

```bash
/novel-research 唐朝长安城布局
```

**输出示例**:
```
📚 资料检索完成

✅ 结论已生成，保存于：E:\dshwork\novel_research\2026-10-17T10-30-00-abc12345.md

📊 来源元数据评分概况（仅供参考）：
- 平均参考分：85分（示例）
- 高区间来源：4/5（示例）
- 成功抓取正文：5/5

💡 提示：评分不验证事实真伪，不自动排序或筛选；所有来源、事实和结论都需要人工核验。
```

**参考分区间**（不是事实核验结论）:
- 🟢 **高区间** (80-100分): 仍需核验，不能直接采用
- 🟡 **中区间** (60-79分): 建议交叉核验
- 🟠 **低区间** (40-59分): 仅作参考并核验
- 🔴 **极低区间** (0-39分): 不应仅凭此分数判断是否使用

### 2. 热点题材静态演示

**命令**: `/novel-trends [时间范围]`

**功能**: 展示插件内置的静态演示数据，不是当前热门题材、市场趋势或市场推荐。

**使用示例**:

```bash
/novel-trends          # 默认参数 7d，显示静态演示
/novel-trends 7d       # 与其他范围使用相同数据
/novel-trends 30d      # 与其他范围使用相同数据
/novel-trends 90d      # 与其他范围使用相同数据
```

**输出边界**:
- 固定展示 6 个题材样例；分值、趋势标签和增长率均为虚构演示字段，不是排行或市场观测。
- 创意组合只是静态灵感示例，不是市场机会预测或推荐。
- 不查询平台榜单、社交媒体或其他实时来源；不能据此判断题材需求、增长或入场时机。

**示例输出**:
```markdown
# 📈 热点题材静态演示报告

> 静态演示：非真实市场数据；不同时间范围使用相同静态数据。

## 静态题材样例（非真实排行）

### 演示 1. 都市修仙（虚构分数：95）
- **虚构趋势标签**：rising；**虚构增长率**：+25%
- **题材元素示例**：系统流、灵气复苏、都市异能

## 静态创意组合示例（非市场机会预测）

### 演示 1. 都市修仙 + AI人工智能
仅作创作灵感示例。
```

## 📊 来源元数据启发式评分说明

### 评分维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 来源类别 | 60% | 0–100 子分；按 URL hostname 与代码内已知域名后缀匹配，不按路径、查询参数或任意子串识别 |
| 时效性 | 30% | 0–100 子分；未知、无效或未来日期不加分 |
| 抓取状态 | 10% | 0–100 子分；成功抓取记 100，最多贡献最终分 10 分，而不是额外加 20 分 |

最终参考分 = 来源类别子分 × 60% + 时效性子分 × 30% + 抓取状态子分 × 10%，并限制在 0–100。该启发式只用元数据，不核验来源内容或事实真伪；结果不按分数排序或筛选。所有事实、结论和引用都应人工核验。

显示分档（仅供参考）：高 80–100，中 60–79，低 40–59，极低 0–39。分档不代表事实核实结果，也不表示可以直接采用。

## ❓ 常见问题

### Q1: 为什么有些来源参考分较低？

**A**: 该参考分是基于来源 hostname 类别、发布日期和正文抓取状态的元数据启发式，不核验来源权威性或事实真假。请查看原始材料并人工交叉核验，不能只凭分数判断是否采用。

---

### Q2: 如何提高检索质量？

**A**:
1. 使用更精确的关键词
2. 配置 `reasoningEffort: high` 提升分析深度
3. 增加 `maxResults` 获取更多来源
4. 选择推理能力强的模型（如 GPT-4, Claude 3.5）
5. 人工核验来源、事实与结论

---

### Q3: 热点演示的数据从哪来？

**A**: `/novel-trends` 展示插件内置的 6 个静态演示样例，不查询平台榜单、社交媒体或其他实时来源。7d/30d/90d 返回相同数据；分数、趋势标签和增长率均为虚构演示字段，创意组合不是市场机会推荐。

---

### Q4: 可以自定义评分规则吗？

**A**: 当前使用固定算法。如需定制，可以修改 `src/research.js` 中的 `CredibilityEvaluator` 类。
