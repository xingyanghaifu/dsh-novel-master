# 智能能力扩展：执行提示与验收要求

本文件将用户需求具体化为实施提示，当前目标是提供用户可控制的功能选择、按模型隔离的经验总结，以及可审计的决策模型调用。

## 完善后的执行提示

扩展小说创作插件的设置页面，让用户按写作、规划、分析、项目管理和智能辅助分类查看功能。每项功能提供独立开关，支持组内启用/停用及全选/全关，显示当前启用数量；修改后热更新注册，保留独立更新维护入口。批量操作只修改目标功能，不覆盖无关设置。

实现自主学习总结：提供学习总开关、自动总结开关、经验复用开关、存储目录、摘要模型、输入上限、记录容量和触发间隔。目录可为工作目录内相对地址或用户指定的绝对地址。按工作目录、实际 provider/model 建立独立记录目录；保留来源模型、摘要生成模型、时间和来源标记，不能仅凭模型显示名合并数据。

自动学习只针对插件发起的小说任务及其成功输出，收集有明确长度上限的文本，不遍历任意会话或私有凭证，不保存隐藏推理。学习是生成经验记录和后续引用，不修改模型权重。摘要应区分观察、可迁移建议和不确定信息，不能把模型自评当成已验证事实。记录达到配置上限时停止追加并显示状态，不擅自删除旧资料。

复用经验必须限定在当前已确认的实际模型与工作目录下，并以参考资料加入可见、持久化的任务提示。不能暗中改写宿主冻结的模型请求。模型身份未知时明确提示或跳过，不使用全局默认模型冒充当前模型。

将剧情分岔、审校取舍和经验提炼中需要选择的部分接入用户指定的决策 provider/model。由模型在明确给定的选项中选择，返回简短依据、置信度和是否需要人工复核。校验结构和选项合法性；不凭模型名称推断能力。超时、取消、调用失败、非法结果或低置信度不能当作成功决策，交回用户判断。

决策建议不授予文件删除、覆盖、恢复或对外发布权限。保留独立决策记录，标明实际决策模型与来源模型。关掉功能后不再发起新调用，卸载时取消未完成任务并清理监听；旧记录保留，提供查询方式。

## 验收边界

- 功能开关、批量选择与学习/决策设置使用宿主 revision 保存，保留热更新和并发配置保护。
- 模型调用走 DSH llm 服务，使用明确 provider/model；输出长度、调用时限和重入都有边界。
- 不同模型、同名 provider/model 路径及不同工作目录不能互相覆盖或读取错误命名空间。
- 自动总结失败不会打断正文写作，失败原因可查询；手动操作返回准确错误。
- 存储写入原子化并拒绝链接绕过，容量策略不静默清空用户资料。
- 测试涵盖开关、模型隔离、自动触发范围、取消、低置信度、错误 JSON、记录查询和热重载清理。
- 文档区分已实现行为、模型生成建议、安装到磁盘与当前运行实例是否生效。
