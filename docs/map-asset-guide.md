# 地图底图绑定使用指南

> 适用于 v2.4.0 及以上版本。

## 功能概述

插件支持 **四种资产类型**：角色立绘、场景地图、物品道具、**世界地图底图**。

绑定「世界地图底图」后，AI 生成的图片会铺在设定树地图的矢量层下方，矢量地形以半透明叠加其上——既保留真实画面，又能看清地区名与事件数量。

## 完整流程

### 1. 配置生图模型

打开「设置 → 小说创作大师 → AI 生图」，分别配置两组模型：

| 配置项 | 作用 | 示例 |
|---|---|---|
| **对话模型** | 把一句话描述扩写成专业生图提示词 | `gpt-4o` |
| **生图模型** | 实际生成图片 | `gpt-image-1` / `dall-e-3` |

- 接口地址填到 `/v1` 为止，插件自动拼接 `/chat/completions` 与 `/images/generations`
- 模型名可点「选择 (N)」从 DSH 列表搜索，也可直接手填中转站的模型 ID
- 密钥只保存在本机配置，请求由宿主进程发出，不受浏览器跨域限制

### 2. 打开生图工作台

右侧栏 → **生图工作台** 页签。

### 3. 生成地图底图

1. **资产类型**选择「世界地图底图」
2. **描述**输入一句话，例如：`一张奇幻大陆地图，有山脉、河流、森林`
3. 点击 **① 扩写提示词** —— 对话模型会写出符合地图风格的英文提示词
4. （可选）手动编辑提示词
5. 点击 **② 生成图片**
6. **绑定目标**填 `地图` 或任意名字
7. 点击 **③ 保存并绑定**

### 4. 查看效果

切换到「设定树 → 地图」，底图会自动铺在矢量层下方。

### 5. 切换显示模式

地图下方出现切换条：

- **叠加矢量层**（默认）：AI 底图 + 34% 透明度的矢量地形，地区名清晰可见
- **只看底图**：纯 AI 图片，画面干净

> 没有绑定底图时，这条切换栏不会显示。

## 提示词建议

选「世界地图底图」时，插件会给对话模型一段专门的地图提示词引导：

```
a top-down fantasy cartographic world map, hand-drawn parchment style,
mountains drawn as ridgelines, rivers, coastlines, forests,
no text labels, no characters, flat overhead view
```

**建议包含**：
- ✅ 俯视视角（top-down / overhead）
- ✅ 具体地形：山脉、河流、森林、海岸线
- ✅ 手绘或羊皮纸风格

**务必避免**：
- ❌ 文字标注（AI 生成的文字是乱码，会和矢量地名冲突）
- ❌ 人物、建筑特写
- ❌ 透视角度（斜视角无法和平面矢量层对齐）

## 常见问题

**Q：点击生成后没有反应？**
检查「设置 → AI 生图」中生图模型是否配置完整（地址、密钥、模型名）。可点「从中转站拉取模型列表」确认连通性。

**Q：地图上看不到底图？**
1. 确认绑定成功：生图工作台步骤 ③ 应显示为完成状态
2. 检查项目目录下 `插图/资产.json` 是否有 `kind: "map"` 的记录
3. 刷新页面

**Q：底图和矢量层错位怎么办？**
AI 生成的地形与 `地区.md` 里的方位是两套独立信息，无法自动对齐。可以：
- 接受「装饰性底图」效果，只把它当画面纹理
- 或在提示词中描述与地区布局一致的地形分布

**Q：可以用自己的图片吗？**
可以。把图片放进项目 `插图/` 目录，再通过生图工作台的「保存并绑定」指定该文件名（需图片已存在）。
