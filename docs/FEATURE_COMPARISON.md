# 功能与执行方式

此表描述本插件自身的实现，不对未调查的其他产品作独占或功能缺失判断。

| 功能 | 执行方式 | 结果边界 |
|---|---|---|
| 完本/续写 | 提交 DSH goals 或会话任务 | 由模型执行写作工作流，完成情况以项目文件为准 |
| 冲突/节奏/情感/读者/对话 | 提交限定文件范围的模型任务 | 模型分析与示意图，不是真实读者测量 |
| 审校/风格学习/对比 | 文本统计辅助及模型任务 | 模型建议需要结合原文核对 |
| 市场适配 | 经验性提示词 | 无实时市场数据库，不预测真实流量或收益 |
| 详细统计 | 读取本地正文直接计算 | 字数和引号统计有明确规则，不提供客观质量评分 |
| 备份/恢复/差异 | 本地文件快照与校验 | 恢复先预览，明确应用前保留快照 |
| 合并/拆分 | 本地生成新文件 | 源正文保留；不自动统一角色、设定或时间线 |
| 配置 | 宿主 schema 与配置事件 | 总开关及单项开关热更新，目录配置影响下一次调用 |
| 更新拉取 | GitHub 完整 SHA + DSH 插件管理器 | 成功/失败/需要重启分别反馈，不自动批准构建脚本 |

模型功能需要当前会话可用的模型服务。项目文件保存在本地，但提交模型的文本会按当前模型提供方的设置发送；不能把本地文件存储等同于完全离线运行。
